# Abdullah Hospital homepage

Premium, responsive homepage built with the Next.js App Router, TypeScript, Tailwind CSS, Framer Motion and Lucide React.

## Development

- `npm run dev` starts the local development server.
- `npm run build` creates a production build.
- `npm run start` serves the production build.
- `npm run lint` runs Oxlint on the app and component code.

## Before launch

The hospital story, services, clinician details, opening hours, emergency availability, contact information and social links are clearly marked placeholders until verified. Replace the illustrative Unsplash photos with approved hospital images; see `public/assets/README.md`.
